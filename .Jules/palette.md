## 2025-05-18 - [Add Explicit Labels to Share Modal Inputs]
**Learning:** Even when inputs are visually grouped under a text element acting as a label, screen readers require explicit programmatic association. Using React 18's `useId` hook is an effective, robust way to generate these IDs without risking collisions, especially in modals that might be instantiated multiple times or dynamically. Adding `aria-hidden="true"` to decorative icons within interactive elements (like buttons) further clarifies the experience for assistive technologies.
**Action:** Always verify that `<label>` elements have an `htmlFor` attribute that strictly matches the `id` of their corresponding `<input>` or `<textarea>`. Use `useId()` for generating these bindings in React components to guarantee uniqueness across the DOM. Apply `aria-hidden="true"` to any purely visual SVG icons nested inside fully labeled buttons.
