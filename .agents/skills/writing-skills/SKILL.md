# Writing skills

Keep frontmatter precise and contrastive. Put long tables and edge cases in references. Avoid duplicated instructions and broad activation boundaries. Add representative prompt cases, attribute external material with pinned source commits/licenses, and test that the main file is concise enough for progressive disclosure.
