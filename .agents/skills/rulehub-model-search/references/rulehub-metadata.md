# RuleHub metadata

RuleHub is `RuleWorld/RuleHub`, the canonical BNGL model repository for the playground. A normalized entry includes an ID, display name, exact path, origin/tags/category, compatibility flags, optional feature flags, and citation metadata. The manifest is authoritative for discoverability; generated embeddings are only a derivative ranking aid.

Use the compatibility fields to choose a simulation path. An excluded entry is not returned by default. Never treat visibility, featured status, or embedding score as scientific validation.
