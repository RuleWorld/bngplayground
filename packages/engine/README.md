# @ruleworld/engine

Pure TypeScript BioNetGen Language (BNGL) simulation engine. Zero browser dependencies.

## Features

- ODE simulation (CVODE, RK4, RK45, Rosenbrock23)
- Stochastic simulation (Gillespie SSA)
- Network-free simulation (NFsim)
- Sobol sensitivity analysis
- Fisher Information Matrix
- Profile likelihood identifiability
- ABC-SMC Bayesian inference
- Contact map generation and rule-level attribution (which rules a parameter appears in)

## Installation

```bash
npm install @ruleworld/engine
```
