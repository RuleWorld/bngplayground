Loading a lecture model into the Playground

  1. Open the Playground with the button on the task, and open the model file with the other button. The file opens on GitHub.
  2. On GitHub, click the “Copy raw file” button at the top right of the file (two overlapping squares).
  3. In the Playground, click inside the editor, select everything (Cmd+A on a Mac, Ctrl+A on Windows), and paste (Cmd+V or Ctrl+V).
  4. Click Parse.

Or download the file from GitHub and use Load → Local file (BNGL / SBML) in the Playground. Tell us in the report if either way did not work.
