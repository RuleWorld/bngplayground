# MCP Server Installation

The maintained cross-platform installation and client guide is in [`packages/mcp-server/README.md`](../packages/mcp-server/README.md).

It covers:

- local setup on Windows, macOS, and Linux;
- Claude Desktop, Claude Code, and Codex configuration;
- the remote-transport requirements for ChatGPT, Claude.ai, and Claude Cowork;
- MCP Apps setup and the interactive simulation/contact-map result views;
- the complete 44-tool capability list; and
- startup, path, cloud-sync, and module-resolution troubleshooting.
