## 2024-05-19 - Accessible Toggle Buttons
**Learning:** Adding static `aria-label`s to buttons that possess dynamic visible text representing state (e.g., "X: LINEAR" / "X: LOG") is an accessibility anti-pattern. This overrides the button's inner text for assistive technologies, violating WCAG 2.1 Success Criterion 2.5.3 (Label in Name), which breaks voice navigation and hides necessary state information from screen reader users. For instance, voice-control users cannot interact with the button by saying its visible text if the `aria-label` doesn't contain it.
**Action:** When making stateful toggle buttons accessible, prioritize using `aria-pressed` (e.g., `aria-pressed={isLogScale}`) to denote the current active state. If an `aria-label` is still necessary to provide more context, ensure it dynamically includes the currently visible text (e.g., `aria-label={\`Switch X-axis. Currently \${xAxisScale} scale\`}`).
